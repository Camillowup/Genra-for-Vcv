# MONK-1's drawing code

From [charlesvestal/fm1-monk](https://github.com/charlesvestal/fm1-monk) v0.9.1 (GPL-3.0-only):

- `face.c` (firmware/src/app/face.c): the singer, its face states, the ToonMouth and the raster. Only change: its include of `../dsp/fastmath.h` reads `fastmath.h`.
- `inflate.c` (firmware/src/app/inflate.c), `fastmath.h` (firmware/src/dsp/fastmath.h): unchanged.
- `art.h`: generated by `python3 tools/gen_art.py art.h` in fm1-monk from its `assets/characters/` (the drawings of MonkSynth's iOS port).

Not compiled on their own: `../monkface.c` includes them.
