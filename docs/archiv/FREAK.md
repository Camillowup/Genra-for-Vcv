# Freak – Projekt auf Eis (Stand 10. Nov. 2026)

Das eigene Repo `Camillowup/Vcv-Freak` war leer, es gab keinen Code. Die Arbeit an Freak bestand
nur aus Entwürfen im Chat. Diese Notiz hält die Entscheidungen fest, damit man das Projekt später
wieder aufnehmen kann.

## Idee

- Neue Marke „Freak“: die Module von GENRA Instruments in neuem Look.
- Die Module bleiben einzeln, wie bisher. Nur Optik und Visualisierung werden neu gestaltet.
- Ein grosses Bild läuft über mehrere Panels hinweg.

## Welche Module

- Alle neun Module von GENRA Instruments (Ordner `instruments/` in diesem Repo),
  dazu DRUM-X und WELT.
- Das Bild darf über zwei Reihen in Rack gehen.

## Look (gewählt)

- Gedämpfter Cyberpunk-/Solarpunk-Look: Neon-Stadt bei Nacht in Blau, Türkis, Violett und Rosa.
  Kein Steampunk.
- Ausprobierte Motive: „Freak-Maschine“ und „Riesenwesen“. Gewählt wurde danach die Stadt.
- **Variante B:** dunkleres Glas über dem Bild. Die Stadt tritt zurück, damit Beschriftungen und
  Regler gut lesbar bleiben.
- Die Stadt fein zeichnen.
- Alle Module bekommen einheitlich dieselben Leuchtfarben, keine eigene Akzentfarbe pro Modul.
- Das Bild ist eine eigene Zeichnung, keine fremde Vorlage.
- Regler dürfen sich im Entwurf nie überlappen.
- Sonst gelten die Regeln aus `docs/DESIGN.md` (GENRA-Leiste, gleiche Anordnung der Ein- und
  Ausgänge, Beleuchtung, dunkle Drehregler).

## Status

- Nur Entwurfsphase, nichts gebaut. Die Beispiel-Panels gab es nur im Chat.
- Am 10. Nov. 2026 auf Eis gelegt. Stattdessen wird GENRA Instruments um weitere Instrumente
  erweitert.
